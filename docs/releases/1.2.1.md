# Quartz Client 1.2.1

This prerelease expands the TypeScript scripting runtime and hardens long-running background operation.

## Highlights

- Exposes live `Audio.rms` and `Audio.peak` levels through `@quartz/client`.
- Adds media playback and track-change scripting events.
- Adds script priorities and `ShaderMutex` arbitration for coordinated shader automation.
- Bundles `scripts/music.automation.ts`, combining immediate MPRIS playback response with configurable RMS attack and release detection.
- Prevents transient `/proc` process exits from terminating the client during background polling.
- Guards TextEditor coordinate conversion against stale rows after live document replacement.

## Music automation

The bundled example switches immediately when a player reports `Playing=true`. While playback remains active, silence does not release the visualizer. When MPRIS reports that playback has stopped, RMS detection takes over using configurable threshold, attack-time, and release-time properties.

This remains a prerelease and a personal development tool. Native-process memory writes, breakpoints, and instruction patching can crash the target process; use them only on software you are comfortable disrupting.
