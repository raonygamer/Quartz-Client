# Quartz Client 1.2.0

This prerelease is the large scripting and reverse-engineering workspace update.

## Highlights

- TypeScript-first Scripts workspace on top of QuickJS, including completion, hover help, diagnostics, external-source reload, and copyable console/state/storage views.
- Shared/lockable process selection across the RE workspace plus module-aware address expressions and `Ctrl+Shift+E` evaluation.
- Reworked memory scanner and watch list with asynchronous scanning, editable/freezeable watches, better context actions, and architecture-aware x86/x64 pointer handling.
- Hardware memory-access monitoring and one-shot execution probes with register snapshots.
- Reworked x86/x64 disassembler with asynchronous lazy window fetching, module-relative addresses, semantic instruction/register hovers, navigation history, Go To, bookmarks, raw-byte synchronization, and asynchronous function hints.
- Persistent control-flow visualization with clickable local routes and aggregated far/cross-boundary routes instead of filling the viewport with long arrows.
- Integrated assembler/patch workflow with preview, verification, NOP fill options, patch history, and restore support.
- TypeScript-defined object experiments with nested structs, arrays, pointers, `CString`, and `WString` fields.
- libhat-backed signature scanning and architecture-aware relocation wildcarding while deriving patterns.
- Large EN-US / pt-BR localization pass across the current UI and RE explanations.
- Appearance/configuration cleanup, including editor presentation, UI rounding/background controls, and host-side signature-scan configuration.

## Final audit fixes

- Fixed pointer scans/watches assuming 8-byte pointers when inspecting 32-bit targets.
- Fixed relocation-aware pattern derivation always initializing Zydis as x64.
- Hardened lazy disassembly paging by moving memory-window fetches off the UI thread and deferring backing-text swaps while PageUp/PageDown is repeating.
- Pruned stale flow-graph state around recycled disassembly windows and tightened bounds checks around editor geometry.
- Cleaned additional untranslated scanner/watch/disassembler statuses and explanations.

## Notes

This remains a prerelease and a personal development tool. Native-process memory writes, breakpoints and instruction patching can crash the target process; use them on software you are comfortable breaking.
